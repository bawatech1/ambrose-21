# Ambrose @ 21 — Final Creative Upgrade

Plain HTML, CSS and JavaScript. No build step, no libraries, no paid services. All paths are relative, so it works on a GitHub Pages project URL.

## Files
- `index.html`, `css/style.css`, `js/script.js`
- `assets/images/`: `ambrose-01-studio.jpg`, `ambrose-02-red.jpg`, `ambrose-03-plaid.jpg`, `ambrose-04-blue.jpg`
- `assets/audio/birthday.m4a`

Keep these filenames exactly, in lowercase.

## The three stages
1. **Anticipation** — a midnight-and-gold lock screen. Enter the birth year (keyboard or on-screen keypad). A wrong year shakes the panel with a warm glow and lets him try again, with unlimited attempts. The right year lights the digits, opens the lock, spins the rings, blooms gold light and bursts into particles. It is a playful interaction, not real security.
2. **Celebration** — the welcome is a birthday wish only: animated heading, portrait reveal with a moving gold border, confetti and fireworks. The button "Let the celebration begin" enters the main experience.
3. **Emotion and brotherhood** — Celebrate (21 sparks to light), Journey since 2019, four-photo gallery with full-screen lightbox, sealed letter (text unchanged), prayer and five wishes, and a fireworks finale with "Launch the fireworks" and "Experience it again".

## Audio
The music starts when the correct year is entered (a user action, so browsers allow it). The round player button at the bottom right pauses and resumes. If audio fails, the player says so and the site keeps working.

## Preview on Windows (VS Code)
1. Open the `ambrose-21` folder in VS Code.
2. Install the **Live Server** extension, right-click `index.html`, choose **Open with Live Server**.

Test the audio through Live Server rather than by double-clicking `index.html`.

## Publish with GitHub Desktop
1. Copy these files over your existing repository folder, keeping the folder structure.
2. In GitHub Desktop, check the changes list shows `index.html`, `css`, `js`, `assets` and `README.md`. Write a summary such as "Final creative upgrade", click **Commit to main**, then **Push origin**.
3. First time only: github.com > repository > Settings > Pages > Deploy from a branch > `main` / `(root)` > Save.
4. Wait 1–2 minutes, then open your Pages address. Hard refresh (Ctrl+F5) if you still see the old version.

## Reduced motion
Visitors with "reduce motion" turned on get a calm version: no particles, no confetti, instant transitions.
